### 🧠 Engineering Philosophy

- **Clarity over complexity**: Simple, maintainable systems beat clever, fragile ones.
- **First principles thinking**: Understand the foundation before adopting high-level abstractions.
- **Practical value**: Build software that solves tangible problems.
- **Security & correctness matter**: Especially when building financial and educational systems.
